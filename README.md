# AlgoPlayground

Une boîte à outils interactive en ligne de commande (CLI) pour expérimenter avec les algorithmes classiques de tri, de recherche et de récursivité, implémentée en Python.

## 🚀 Fonctionnalités

### Algorithmes de Tri
- **Bubble Sort** - Tri à bulles (itératif)
- **Insertion Sort** - Tri par insertion (itératif)
- **Quick Sort** - Tri rapide (version itérative)
- **Merge Sort** - Tri fusion (version récursive)

### Algorithmes de Recherche
- **Recherche Linéaire** (itératif)
- **Recherche Binaire** (itératif et récursif)

### Algorithmes Récursifs
- **Factorielle** 
- **Suite de Fibonacci**
- **Somme d'un tableau**
- **Merge Sort** (tri fusion récursif)
